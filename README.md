# Haven — Property Management Dashboard

A beginner-friendly student project with separate HTML pages, basic CSS, and a tiny JavaScript example. The design is intentionally a first version that a team can keep building.

## Open the project

Open `index.html` in VS Code with the Live Server extension, or open the HTML file in a browser. Use the navigation at the top to switch between pages.

## Pages

- `index.html` — public landing page and links to the project sections.
- `login.html` — login and sign-up form mockups. Forms do not create or validate accounts.
- `properties.html` — property cards and occupancy.
- `tenants.html` — tenant and rent-status table.
- `maintenance.html` — simple maintenance ticket board.
- `style.css` — the shared styles for all pages.
- `data.json` — example project data to refer to when adding more JavaScript later.

The HTML currently contains sample content directly, so you can edit text and learn page structure without needing to write JavaScript. Login and sign-up forms are visual demonstrations; they do not create accounts or save information.

## Suggested split for four people

1. Landing page and shared navigation.
2. Properties and occupancy.
3. Tenants and rent.
4. Maintenance.

Everyone can use the same `style.css` while working on a separate HTML page.
